# carvequery

Carve and reshape query text streams with deterministic transforms.

**Site:** https://theworker02.github.io/carvequery/

## Install / run

```bash
git clone https://github.com/theworker02/carvequery.git
cd carvequery
node src/cli.js
node --test
```
